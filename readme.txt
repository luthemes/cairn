A block theme that puts your work first: a grid of featured images beside a simple sidebar, built with theme.json and the Site Editor.

== Description ==

Cairn is a block theme for portfolios, journals and blogs. Posts appear in a two-column grid of large featured images with the title, categories and date underneath, and a sidebar sits to the right with About, Search, Categories and Recent posts. On small screens the sidebar moves below the posts.

Colors, typography, spacing and layout are all controlled through theme.json and the Site Editor, so no build step or extra plugins are needed. The sidebar is a template part, so you can add, remove and rearrange its blocks in the Site Editor. The theme bundles the Inter font and loads nothing from other websites.

Templates included: posts index, single post with comments, page, archive, search and 404. Header, footer and sidebar are template parts you can edit in the Site Editor.

== Frequently Asked Questions ==

= How do I change the sidebar? =

Open Appearance > Editor > Patterns > Template parts > Sidebar. Add, remove or rearrange blocks there. The sidebar appears on the posts index, archives, search results and single posts.

= How do I change the colors, fonts or layout? =

Open Appearance > Editor > Styles. Everything defined in theme.json can be changed there.

= Does the theme load anything from other websites? =

No. The font is bundled with the theme and no external scripts, styles or images are loaded.

= Does the theme collect any data? =

No. The theme does not track visitors or collect any data.
